# VS Code 代码编辑快捷键速查表（Windows）

## 一、光标移动

| 快捷键         | 功能             |
|----------------|------------------|
| `← / →`        | 左右移动一个字符 |
| `↑ / ↓`        | 上下移动一行     |
| `Ctrl + ← / →` | 按单词移动       |
| `Home`         | 移到行首         |
| `End`          | 移到行尾         |
| `Ctrl + Home`  | 移到文件开头     |
| `Ctrl + End`   | 移到文件末尾     |
| `PageUp`       | 向上翻一页       |
| `PageDown`     | 向下翻一页       |

---

## 二、文本选择

| 快捷键                 | 功能                |
|------------------------|---------------------|
| `Shift + ← / →`        | 向左/右选择一个字符 |
| `Shift + ↑ / ↓`        | 向上/下选择一行     |
| `Ctrl + Shift + ← / →` | 按单词选择          |
| `Shift + Home`         | 选择到行首          |
| `Shift + End`          | 选择到行尾          |
| `Ctrl + Shift + Home`  | 选择到文件开头      |
| `Ctrl + Shift + End`   | 选择到文件末尾      |
| `Ctrl + A`             | 全选                |

---

## 三、删除与修改

| 快捷键             | 功能                |
|--------------------|---------------------|
| `Backspace`        | 删除光标左侧字符    |
| `Delete`           | 删除光标右侧字符    |
| `Ctrl + Backspace` | 删除左侧一个单词    |

| `Ctrl + C`         | 复制当前行/选中内容 |
| `Ctrl + V`         | 粘贴                |
| `Ctrl + Z`         | 撤销                |
| `Ctrl + Y`         | 重做                |

## 七、多光标编辑

| 快捷键             | 功能                         |
|--------------------|------------------------------|
| `Alt + 鼠标左键`   | 添加光标                     |
| `Ctrl + Alt + ↑`   | 向上添加光标                 |
| `Ctrl + Alt + ↓`   | 向下添加光标                 |
| `Ctrl + D`         | 选择下一个相同内容并添加光标 |
| `Ctrl + Shift + L` | 为所有相同内容添加光标       |
| `Esc`              | 退出多光标模式               |

### 示例

原代码：

```cpp
int a = 10;
int b = 20;
int c = 30;
```

选中 `int` 后按：

```text
Ctrl + Shift + L
```

可以同时编辑三个 `int`。

---

## 八、代码注释

| 快捷键                  | 功能         |
|-------------------------|--------------|
| `Ctrl + /`              | 切换单行注释 |
| `Shift + Alt + A`       | 切换块注释   |
| `Ctrl + K` → `Ctrl + C` | 添加行注释   |
| `Ctrl + K` → `Ctrl + U` | 删除行注释   |

### C++ 示例

```cpp
int a = 10;
int b = 20;
```

选中两行后按：

```text
Ctrl + /
```

变成：

```cpp
// int a = 10;
// int b = 20;
```

## 九、括号与代码跳转

| 快捷键             | 功能             |
|--------------------|------------------|
| `Ctrl + Shift + \` | 跳转到匹配的括号 |
| `Ctrl + ]`         | 增加缩进         |
| `Ctrl + [`         | 减少缩进         |
| `F12`              | 跳转到定义       |
| `Alt + F12`        | 查看定义         |
| `Ctrl + 鼠标左键`  | 跳转到定义       |
| `Shift + F12`      | 查看引用         |
| `F2`               | 重命名符号       |

例如：

```cpp
void func();

int main() {
    func();
}
```

光标放在 `func()` 上按：

```text
F12
```

可以跳转到 `func()` 的定义。

## 十、代码折叠

| 快捷键                  | 功能           |
|-------------------------|----------------|
| `Ctrl + Shift + [`      | 折叠当前代码块 |
| `Ctrl + Shift + ]`      | 展开当前代码块 |
| `Ctrl + K` → `Ctrl + 0` | 折叠全部       |
| `Ctrl + K` → `Ctrl + J` | 展开全部       |

例如：

```cpp
int main() {
    // 大量代码
    if (x > 0) {
        // 大量代码
    }
}
```

可以折叠成：

```cpp
int main() {...}
```

# 一个比较实用的 C++ 编辑习惯

```text
写代码
  ↓
Ctrl + S
  ↓
Shift + Alt + F        格式化
  ↓
F12                    查看定义
  ↓
Shift + F12            查看哪里被调用
  ↓
Ctrl + .               快速修复
  ↓
F8 / Shift + F8        检查错误
```

尤其是你现在写 C++，建议优先把 `Ctrl + /`、`Alt + ↑/↓`、`Shift + Alt + ↑/↓`、`Ctrl + D`、`F12`、`Shift + F12`、`F2`、`Ctrl + .` 这几个练熟，它们对实际编码效率提升比较明显。
